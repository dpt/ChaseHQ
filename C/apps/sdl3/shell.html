This is a disassembly and portable C reimplementation of the ZX Spectrum 128K version of Ocean Software's Chase H.Q., built by reverse engineering the original cassette-loaded game and translating its Z80 machine code into readable, heavily-commented C. This page runs that C port compiled to WebAssembly, playing directly from the original game's graphics, level and sound data.
